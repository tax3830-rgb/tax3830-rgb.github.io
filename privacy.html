세무일정관리 개인정보처리방침

시행일: 2026년 11월 10일

1. 앱 소개

세무일정관리는 선정 세무회계 사무소가 내부 업무 일정 관리에만 사용하는 개인용 도구입니다. 사무소 PC에서만 실행되며 일반 사용자에게 제공하지 않습니다.

2. 사용하는 Google 데이터

사용자 본인이 로그인해 허용한 경우에 한해, Google 캘린더 일정(제목, 설명, 날짜)을 읽고 등록·수정·삭제합니다. 요청하는 권한은 캘린더 일정 보기·수정(calendar.events) 하나입니다.

3. 데이터 처리와 보관

  • 캘린더 데이터는 사무소 PC와 Google 사이에서만 오가며, 다른 서버나 제3자에게 전송·판매·공유하지 않습니다.
  • 로그인 정보(토큰)는 사무소 PC에만 저장됩니다.
  • 광고, 분석, 인공지능 학습 등 일정 관리 외의 목적으로 사용하지 않습니다.

4. 권한 철회

Google 계정 설정의 서드 파티 액세스에서 언제든지 이 앱의 권한을 철회할 수 있습니다. 철회하면 앱은 더 이상 캘린더에 접근하지 못합니다.

5. Google API 서비스 사용자 데이터 정책 준수

이 앱이 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

6. 문의

문의는 Google 로그인 동의 화면에 표시되는 지원 이메일로 해 주세요.
